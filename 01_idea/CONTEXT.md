# Stage: Idea

## Job

Choose the one idea the team builds and state it so anyone can say it in one sentence.

## Inputs

`_config/rules.md`, `_config/rubric.md`, `_config/judges.md`.

## Process

1. For each candidate, write the problem in one sentence, the person who has it, the moment that films well, the prizes it enters, the build risk for a team new to n8n, and how many other teams might build it.
2. Rate each against the rubric, and update the ratings when a track judge answers.
3. Before committing, call every outside source the top idea depends on. If one fails, move to the next candidate.
4. Write the choice and its golden path, in five steps or fewer.

## Audit

- [ ] Every teammate can say the problem in one sentence.
- [ ] Every outside source the idea depends on answered a live call.
- [ ] The pick names a fallback if its riskiest step fails.

## Output

`output/pick.md`, with the candidates in `output/ideas.md`.

Stop: Saturday 13:00.
