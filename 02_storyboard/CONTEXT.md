# Stage: Storyboard

## Job

Write the demo video as timed beats before building, and list every step that has to work on camera. That list is the build scope.

## Inputs

`01_idea/output/pick.md`, `_config/rubric.md`.

## Process

1. Draft beats with stable IDs (B1, B2, …) and timecodes, under 2:50 to leave margin. The problem lands in the first 15 seconds.
2. Mark which rubric criterion each beat earns. Every criterion needs at least one beat.
3. List every step the video shows. Give each a test and an owner.
4. When the team approves, add a line starting "Approved" with the date to `storyboard.md`.

## Audit

- [ ] Read aloud with a timer, the narration runs under 2:50.
- [ ] Every step on camera is in `must-work.md` with a test.
- [ ] Every number in the narration comes from real data pulled that day.

## Output

`output/storyboard.md`, `output/must-work.md`.

Stop: Saturday 14:00.
