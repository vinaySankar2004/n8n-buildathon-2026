# Failures

What broke, how it was fixed, and the check that would catch it again.

- **F1, 2026-11-14. The countdown ran an hour early.** Node's bundled time zone data and macOS disagree about Vancouver's offset. Fix: the architecture server sends wall-clock times with no offset, and the browser reads them in the computer's own zone. Check: the page's next stop matches the clock on the wall.
- **F2, 2026-11-14. We said the 3-1-1 data updates every few hours.** A live check showed it refreshes once a day. Fix: corrected in the pick and the storyboard. Check: the architecture page shows the dataset's latest update time.
- **F3, 2026-11-14. The n8n Cloud trial blocks the public API.** Settings, n8n API shows "Upgrade to use API", so `npm run sync` cannot run. Fix: n8n is self-hosted on the host laptop, where the API is on (D11). Check: `npm run deploy` and `npm run sync` both run.
- **F4, 2026-11-14. Building permit days came out one day early.** `issuedate` has no time, so the API stores it at UTC midnight, and grouping in Vancouver time moved every permit to the day before. Fix: a source with `date_only: true` is grouped in UTC. Check: `npm run test:pipeline` confirms each source's neighbourhood counts add up to its weekly count.
- **F5, 2026-11-14. The first draft of Score picked "election inquiries fell to 0".** A category dropping to zero is usually a season or program ending, and it leaves no neighbourhoods to chart. Fix: drops must stay above zero, and a drop story charts the weekly trend. Check: `npm run test:pipeline` prints the top story and runners-up.
- **F6, 2026-11-14. One missing credential stopped the whole deploy.** n8n refuses to activate a workflow whose credential does not exist, and deploy stopped at "3 Write", leaving Voice, Publish and the orchestrator undeployed. Fix: deploy saves such a workflow, says it is not active and why, and carries on. Check: `npm run deploy` with a blank key in `.env` still deploys the other workflows.
- **F7, 2026-11-14. Voice sent no ElevenLabs key.** "4 Voice" was deployed before the ElevenLabs credential existed, so its node kept an empty credential link and ElevenLabs answered 401; the run ended in "No story today". Fix: deploy links every node credential to its id by name on every deploy. Check: `npm run deploy` then `npm run invoke -- voice` returns `ok: true`.
- **F8, 2026-11-14. The first real narration ran 28.1 seconds.** Claude kept to the prompt's 45 to 55 words but put the date in digits and named 3 neighbourhoods, and the ElevenLabs voice reads about 2.3 words a second, so "4 Voice" stopped it at the 22 second limit. Fix: the prompt asks for 35 to 45 words, "this week" instead of a date, at most 2 neighbourhoods, and leaves the source to the screen; the check blocks scripts outside 25 to 50 words. The rerun was 42 words and 18.9 seconds. Check: `npm run invoke -- write` on a Score result, then `npm run invoke -- voice` on that, returns `audio_seconds` under 22.
- **F9, 2026-11-14. The first full run never reached Slack.** The orchestrator called "6 Publish" with "wait for sub-workflow" off, so its approval wait would not hold the run. In n8n 2.47 that started an execution that ran no nodes and finished in 8 ms as a success, so nothing showed it failed. Run on its own, Publish sent the video and waited for a button. Fix: the orchestrator waits for Publish like every other step. Check: after `npm run invoke -- orchestrator`, the newest "6 Publish" execution is waiting at "Ask editor" and the video is in the editor channel.
- **F10, 2026-11-14. The first video for a review thread never reached Slack.** Slack answered `not_in_channel`: the bot can post messages to a channel it is not in (chat:write.public), but uploading a file needs it to be a member. The note to the editor also said "a step stopped without saying why", because the Slack node puts its error in `error` as text. Fix: the bot joined the editor and outlet channels, and the failure notes read text errors. Check: approve a script in a review thread and the video arrives in the thread; if not, the note names Slack's error.
- **F11, 2026-11-14. The bot refused to switch to the weekly chart.** The chat prompt said "only weekly if by_area is empty", which Claude read as a ban, and it named the JSON field in its answer. Fix: the prompt says either chart is fine when the editor asks, and to talk in plain words. Check: in a review thread, "use the weekly chart" gets a draft whose bars are the last 6 weeks.
- **F12, 2026-11-14. Deploy printed "npm run invoke -- undefined" for 2b Context, and invoke refused it.** The step list in `tools/n8n-api.mjs` did not have "context". Fix: added it. Check: `npm run invoke -- context` returns `ok: true` with `reports` and three entries in `feeds_checked`.
- **F13, 2026-11-14. The first trace page showed times an hour early.** The same cause as F1: the render service formatted Vancouver time with Node's zone data. Fix: the page carries exact times and the reader's browser shows them in its own zone. Check: open a trace in a browser; "run started" matches the Slack message's time.
- **F14, 2026-11-14. Thread replies never reached 7 Chat, though the buttons worked.** Slack sent no message events at all: Event Subscriptions had just been switched on, and the app had not been reinstalled, so the bot lacked `channels:history`. The router had also been running its old code until it was restarted, which is when it began checking `SLACK_SIGNING_SECRET`. Fix: save Event Subscriptions with `message.channels` and `message.groups`, reinstall the app, restart the router (`npm run host` after stopping it). Check: reply in a review thread; ngrok's inspector at `127.0.0.1:4040` shows a `/slack/events` message, and the bot answers in the thread within a few seconds. The first live reply, "Lead with Mount Pleasant", was revised by Haiku in 3.5 seconds.
- **F15, 2026-11-15. Adding 2c Reddit switched off 2b Context for a few minutes.** n8n 2.47 will not switch on a workflow until every sub-workflow it calls is switched on, and 2c Reddit cannot be switched on before its Reddit credential exists. Deploying the new Context therefore left it off, and every story runs through it. Fix: Context calls 2c Reddit only when the client config's `reddit.enabled` is true, which stays false until the credential is connected; Context was redeployed without the call and is on again. Check: after any deploy, `npm run doctor` lists no workflow other than 2c Reddit as deployed but not active.
- **F16, 2026-11-15. No route to Reddit before the deadline.** Making a Reddit app now shows Reddit's Responsible Builder Policy: API access waits for Reddit's approval. Anthropic's web search with `allowed_domains: ["reddit.com"]` answers 400, "The following domains are not accessible to our user agent: ['reddit.com']". Reddit's public search and feeds answer 403 and 429 without an app. Fix: 2c Reddit stays built and tested but off (`reddit.enabled: false`), so 2b Context runs without it; both the API and web search versions are ready. Check: `npm run invoke -- reddit` returns `reactions.relevant: true` before Reddit is turned on.
- **F17, 2026-11-15. With Reddit off, every scheduled story stopped silently after 2b Context.** The "Asked in Slack?" branch for stories nobody asked for led nowhere once 2c Reddit was left out, so Context returned no item and the orchestrator ended without Write or a "No story today" note. Slack requests still worked, which hid it. Fix: that branch ends at a pass-through node, "Not asked". Check: `npm run invoke -- orchestrator` reaches 3 Write and posts a review card; the live guard test then got "Blocked: 38 in script", and three runs in a row reached the card.
